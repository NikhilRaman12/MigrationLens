# MigrationLens Frontend & API Agent

This directory contains the Next.js frontend application and migration agent API route for **MigrationLens** (DEV.to Sanity Challenge Entry).

For complete architecture documentation, data model diagrams, and challenge alignment details, see the root [README.md](../README.md).

## Quick Start

```bash
# Install dependencies
npm install

# Run production build check
npm run build

# Start dev server
npm run dev
```
